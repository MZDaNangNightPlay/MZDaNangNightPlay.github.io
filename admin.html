① GitHub 연결

이 관리 페이지는 GitHub Pages에서 작동합니다. 편집 내용은 GitHub에 직접 저장되며, 로그인 토큰은 서버에 저장하지 않고 현재 페이지 메모리에서만 사용합니다. 이 페이지의 주소는 공개되어 있으므로 토큰을 다른 사람에게 알려주지 마세요.

토큰 만드는 방법

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access는 Only select repositories에서 MZDaNangNightPlay.github.io를 선택하고 Repository permissions의 Contents: Read and write를 지정하세요. 만료 기간은 짧게 설정하세요. 토큰은 브라우저에 저장하지 않습니다.

먼저 토큰을 입력하고 불러오기를 누르세요.
